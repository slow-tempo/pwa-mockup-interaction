# pwa-mockup-interaction

Keep single-file PWA mockup interactions fast and side-effect free: redraw only the changed region, bind each listener once, and verify each click produces exactly one effect.

## Skills

- **pwa-mockup-interaction** — Keep single-file PWA mockup interactions fast and side-effect free by redrawing only the changed region, binding each listener once, and verifying each click produces exactly one effect.

## Install

**As agent skills** (any agent that reads `SKILL.md`):

```bash
npx skills add slow-tempo/pwa-mockup-interaction
```

or copy `skills/*/` into your skills directory
(`~/.agents/skills/`, `.claude/skills/`, or your Antigravity/Gemini
plugin skills dir).

**Quick install script:**

```bash
./install.sh              # → ~/.agents/skills/
./install.sh /target/dir  # → custom directory
```
